# ASR Noise Robustness in Spoken Language Intent Classification

This repository contains the code, data, and results for the paper:

**"How Robust Are Intent Classifiers to ASR Noise? A Systematic Comparison of Traditional Models, BERT, and Large Language Models"**

---

## What This Research Is About

Voice-based systems convert speech to text using ASR (Automatic Speech Recognition), then classify the intent of that text. ASR systems are not perfect - they make transcription errors, and those errors hurt classification accuracy downstream. This paper asks a simple but unanswered question: which type of model handles those errors best?

We tested four model types - TF-IDF + SVM, TF-IDF + Logistic Regression, BERT, and a fine-tuned large language model (Qwen2.5-3B with QLoRA) - on the SLURP spoken language benchmark (66 intent classes). We injected controlled noise at 6 word error rate levels (0%, 10%, 20%, 30%, 40%, 50%) and measured how each model degraded.

**Main findings:**
- The fine-tuned LLM maintained higher accuracy at every noise level above zero
- BERT degraded the most steeply, dropping 28.2 Macro F1 points from clean to WER=50%
- The LLM dropped only 20.8 points - a 7.4 point advantage at maximum noise
- TF-IDF models showed an unexpected two-phase degradation pattern: a sharp initial drop at WER=10% followed by relative stability up to WER=30%
- This is the first published LLM classification benchmark on the SLURP dataset

## How to Reproduce

### 1. Install dependencies

```bash
pip install torch transformers datasets peft bitsandbytes
pip install scikit-learn pandas numpy tqdm matplotlib seaborn
```

Tested on Python 3.11, PyTorch 2.11.0, Transformers 5.4.0, PEFT 0.x.
Hardware: NVIDIA RTX 4070 Super (12 GB VRAM).

### 2. Download and prepare the dataset

```bash
python scripts/1_download_slurp.py
```

This downloads SLURP from HuggingFace (`qmeeus/slurp`) and saves the processed
train/val/test splits to `research_data/`.

### 3. Train baseline models

```bash
python scripts/2_baseline_models.py
```

Trains TF-IDF + SVM, TF-IDF + Logistic Regression, and fine-tuned BERT-base.
Takes approximately 35 minutes on GPU.

### 4. Fine-tune the LLM

```bash
python scripts/3_finetune_llm_v3.py
```

Fine-tunes Qwen2.5-3B-Instruct with QLoRA. Requires a GPU with at least 12 GB VRAM.
Takes approximately 9 hours on an RTX 4070 Super.

Set `MODEL_NAME` in the script config to the path of your local Qwen2.5-3B model,
or use the HuggingFace model ID `"Qwen/Qwen2.5-3B-Instruct"` to download automatically.

### 5. Run the noise robustness experiment

```bash
python scripts/5_noise_robustness.py
```

Evaluates all saved models on six noisy test sets (WER = 0 to 50%).
Results are saved to `results/noise_experiment/`.
Takes approximately 2 hours for TF-IDF/BERT and 2 hours per WER level for the LLM.

---

## Pre-generated Noisy Test Sets

The six noisy versions of the SLURP test set used in the paper are provided
in `results/noise_experiment/test_wer[N].csv`. These were generated with a
fixed random seed (42) and are included here so results can be reproduced
exactly without re-running the noise injection.

## Results Summary

| Model | WER=0% | WER=10% | WER=20% | WER=30% | WER=40% | WER=50% | Drop |
|---|---|---|---|---|---|---|---|
| TF-IDF + SVM | 0.7202 | 0.6283 | 0.6323 | 0.6138 | 0.5848 | 0.5480 | 0.1722 |
| TF-IDF + LR | 0.7431 | 0.6294 | 0.6345 | 0.6173 | 0.5977 | 0.5604 | 0.1827 |
| BERT-base | 0.7896 | 0.6539 | 0.6422 | 0.6146 | 0.5745 | 0.5144 | 0.2752 |
| Qwen2.5-3B QLoRA | **0.7964** | **0.7079** | **0.7050** | **0.6737** | **0.6565** | **0.5888** | **0.2076** |

Metric: Macro F1. Dataset: SLURP test set (13,006 utterances, 66 intent classes).
